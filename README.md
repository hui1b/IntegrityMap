# 廉洁文化地图（简约版）

抓取自「全国高校思想政治工作网」的《廉洁文化地图》页面（<https://www.sizhengwang.cn/ljwhdt/>），**数据内容保持不变**，仅将界面重新设计为简约风格。

## 数据

- **238** 个全国高校廉洁文化点位，分布在 **203** 所高校
- **6** 个类别：历史遗迹（11）、纪念场馆（34）、教育基地（123）、艺术作品（25）、文化品牌（29）、学科课程（16）
- 每条点位包含：名称、所在高校、类别、地址、简介、原文详情链接、经纬度

数据来自原站两个接口并做了合并：

- `zcms/front/content/map/index` — 地图点位、经纬度、分类、总数
- `zcms/front/content/map/rank` — 点位列表、简介、详情链接

## 运行

直接双击打开 `index.html` 即可；若需更稳定（部分浏览器对 `file://` 下加载本地脚本有限制），可在本目录启动静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 高德地图配置

项目已改为使用高德地图 JS API。所有需配置的内容集中在 `config.js`：

```js
window.MAP_CONFIG = {
  amap: {
    key: "66eb504794e30df4c7110614de219807",
    securityJsCode: "62908ba063e845fb49b2885503cb0381",
    mapStyle: "amap://styles/fresh"
  },
  map: {
    defaultCenter: [105, 35.5],
    defaultZoom: 4
  }
};
```

如果要替换成自己的高德 key，只需要更新这个文件即可。页面会自动加载 `https://webapi.amap.com/maps`，并在坐标缺失时通过 `AMap.Geocoder` 按地址精确定位。

## 功能

- 顶部统计：点位总数、入选高校、类别数
- 类别筛选、按高校/点位名称搜索
- 地图标记（按类别着色）+ 图例 + 底图切换
- 右侧点位列表，点击标记或列表项查看详情与原文链接
- 若某条地址坐标不全或异常，优先自动调用高德地理编码 API，并在当前 key 未授权时回退到公开地理编码服务，确保点位仍能精准定位并显示在地图上

## 文件结构

```
index.html      主页面（含样式与逻辑，简约风格）
config.js       要配置的高德地图参数（key、securityJsCode、地图样式）
data.js         window.MAP_DATA 数据（供页面加载）
data.json       同一份数据的 JSON（便于二次使用）
leaflet/        本地化的 Leaflet 1.9.4
_src/           抓取的原始页面、接口返回与处理脚本
```

## 备注

原站数据中有一条点位的经纬度有误：`《清莲》（组画）`（江苏警官学院，ID 2272529）的纬度被原站写成了与经度相同的 `118.6626748`（应为南京约 32.06）。为遵守「数据保持不变」，本工程**未改动**该原始数据，仅在地图上跳过渲染这条无效坐标（列表与详情中仍完整保留）。
